📌 Project Title

Salesforce Insurance Portal

📖 Project Description

This project focuses on building a Salesforce-based Insurance Portal that provides a centralized platform for managing insurance-related services such as policy management, customer data handling, and claim processing.

The portal is developed using Salesforce Lightning Components (LWC/Aura) and integrates various Salesforce features to deliver a smooth and user-friendly experience for both customers and administrators.

🚀 Key Features
🔐 User Authentication & Access Control
Secure login system with role-based access for customers and admins.
📄 Policy Management
Create, update, and track insurance policies efficiently.
👤 Customer Data Management
Store and manage customer details using custom objects.
📊 Dashboard & Reports
Interactive dashboards for monitoring policies, claims, and performance.
📑 Claims Processing
Submit and track insurance claims through the portal.
⚡ Lightning Experience UI
Built with modern Salesforce Lightning components for better performance and UX.
